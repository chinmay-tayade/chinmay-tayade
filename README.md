### &nbsp;&nbsp;How I think about engineering

- **Design for the failure case first.** What happens with no signal, on a
  stolen device, mid-migration — that's where the architecture is decided.
- **Share logic, not UI.** In KMP, the domain and data layers are shared; the
  UI stays native. Knowing *what not to share* is the skill.
- **Measure before claiming a win.** A performance number ships with its
  device, build type, and iteration count — or it doesn't ship.
- **A test suite you trust** is worth more than one that's merely green.
